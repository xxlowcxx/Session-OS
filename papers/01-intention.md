# Intention

The goal is the experience of using another OS on the owner's device.

The menu of systems and the session live on the server. The phone shows the result. From the moment the session is on screen, the desktop, the files, the settings, and the buttons are the virtual OS.

The phone's own OS boots first. Then it runs the session. There is one boot.

A list of many systems on a server is a list of sessions. Picking one starts that session. It does not rewrite the phone.

This is designed. It is not built yet.
