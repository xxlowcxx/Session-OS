# Where it runs

Any phone that can run the app, once the owner is already in, can show the session. Android and iOS both.

On an Android the owner sets up, the real OS can open the session as soon as boot finishes. The session's own code is the lock. That code is what keeps other people out. The phone does not have to show its own lock screen first, because the owner chose this while they still controlled the phone.

After a reboot, an iPhone shows its own lock screen until its own code is entered. No app draws over that screen. The session starts after that code.

A phone that is still locked, or not set up, has no session. The app has not started. Android and iOS are the same on this point.

The bootloader can stay locked. The session does not need it open.
